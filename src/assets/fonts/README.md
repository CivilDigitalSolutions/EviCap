# Fonts

`montserrat-latin-wght-normal.woff2` is Montserrat (variable weight, Latin subset), copied from `@fontsource-variable/montserrat` 5.3.0. It is used for EviCap's headings and wordmark (`src/ui/styles.css`). It is licensed under the SIL Open Font License 1.1, in `OFL.txt` here.

Characters outside the Latin subset fall back to the system font.
