Check nothing has been changed

The EviCap checker confirms every file in an export is exactly as it was when it was made. It runs on this computer: nothing is uploaded and no internet connection is used.

Choose the ZIP file you were sent, or the folder you unzipped it into. You can also drag the ZIP file onto this page.

No export checked yet.

What is checked: the SHA-256 hash of every file; the export and capture manifests' ECDSA P-256 signatures, using the public key in the export; every link in the hash-chained audit log; and that each capture matches the audit event that recorded it. The signing key is created by the EviCap installation that made the export. A valid signature shows the files are unchanged since that installation produced them; it does not by itself prove who used it.
